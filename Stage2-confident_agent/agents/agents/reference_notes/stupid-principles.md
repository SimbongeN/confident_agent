# STUPID Software Design (Anti-patterns)
keywords: STUPID, singleton anti-pattern, tight coupling, untestability, premature optimization, indescriptive naming, duplication, DRY, KISS
- STUPID is an acronym for the six things to avoid in software design: Singleton, Tight coupling, Untestability, Premature optimization, Indescriptive naming, Duplication.
- Singleton: treated as an anti-pattern.
- Tight coupling: makes code hard to test.
- Untestability: testing should be easy.
- Premature optimization: evil, do not do it.
- Indescriptive naming: code is for humans.
- Duplication: avoid by following DRY and KISS ('be lazy the right way').
