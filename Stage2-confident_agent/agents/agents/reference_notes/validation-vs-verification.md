# Validation vs verification
keywords: verification, validation, V&V, building the product right, building the right product, Boehm, acceptance testing, reviews
- Verification and validation both check software but answer different questions.
- Verification checks that each development phase correctly implements its input specification (requirements, then design, then code).
- Verification is largely done by reviewing artifacts rather than running the software.
- Validation checks that the finished software meets the needs of all stakeholders such as users, operators and managers.
- Validation is usually confirmed through acceptance testing, which requires running the software.
- Boehm's distinction: verification asks "Are we building the product right?"
- Boehm's distinction: validation asks "Are we building the right product?"
