# SOLID Design Principles Overview
keywords: SOLID, five design principles, SRP OCP LSP ISP DIP, Robert Martin, dependency management, object-oriented design principles
- SOLID stands for the Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation and Dependency Inversion principles.
- The lecture presents SOLID as the way to fix software rot (rigidity, fragility, immobility, viscosity).
- OO designs have principles to manage dependencies between modules, packages and classes; changes that introduce unplanned dependencies cause problems.
- The recommended reading is Robert C. Martin (2000), Design Principles and Design Patterns.
- The Lecture 3 roadmap groups basic principles (SRP, OCP, LSP, DIP, ISP, separation of concerns, program to an interface not an implementation, favour object composition over class inheritance, polymorphism) as class-level design.
- Class-level design principles: SRP, OCP, LSP, DIP, ISP. Package-level principles: REP, CRP, CCP, ADP, SDP, SAP.
