# Java Keywords and Identifiers
keywords: Java keyword, reserved word, identifier, variable name, class name, contextual keyword, compiler

- A Java keyword is a reserved language token with a defined meaning in the language grammar.
- A keyword such as `class`, `if`, or `return` cannot be used as an ordinary identifier.
- An identifier is a name used for program elements such as classes, methods, variables, and packages.
- Java identifiers are case-sensitive, so `total` and `Total` are different identifiers.
- Identifiers cannot begin with a digit, although digits may appear after the first character.
- Java also has contextual keywords whose special meaning depends on where they appear in source code.
- `true`, `false`, and `null` are reserved literals rather than ordinary identifiers.
- A name being familiar or commonly used in programming does not make it a Java keyword; the Java Language Specification defines the language's keywords and lexical rules.
